# 统一文件窗口与内嵌／浮窗路由

## Problem

顶部 Island 在文件落盘时提醒产物，终端右侧 Island 在轮次结束时展示文件改动，同一个文件可能先后出现在两个提醒中。顶部入口打开主窗口内的产物预览列，文件树与终端改动列表则打开独立编辑窗口；相同的文件点击产生不同布局，用户需要记住入口与文件种类的差别。

现有产物预览、内嵌编辑器和独立编辑窗口还分别管理标签与生命周期。仅统一外观不能保证后续文件的打开位置，也不能保证切换宿主后草稿和标签完整保留。

## Decision

用户已确认以下产品方向，统一文件窗口处于实施与验收阶段。本篇维护目标设计；[产物工作区](./product-workspace.md)与[文件编辑窗口体验](./file-editor-experience.md)保留原实现记录，尚不能据此认定统一窗口已完成交付。右侧 Island 定时收起与下述 Office 预览控件已分别实施并验证。

移除顶部 Island 的产出提醒及产物跳转入口，包括胶囊、通知托盘和监控产物分区中的相应入口；其它状态、知识与维护功能保持各自职责。终端右侧 Island 承接本轮改动和历史记录的发现，文件树提供稳定的文件查找入口。保留 OfficeCLI 渲染与文件读取能力，将用户界面的“产物工作区”收敛为统一文件窗口内的预览能力。

### 文件内容与操作

统一文件窗口共用标签栏、打开与关闭行为、文件身份和模式切换。OfficeCLI 内容与普通文件预览／编辑在同一外壳内按文件能力呈现：Office 默认展示 OfficeCLI 渲染，Markdown 与 HTML 默认预览并支持切换源码，代码、配置和普通文本默认编辑，图片使用图片查看器。JSON、YAML、日志等不会仅因可以渲染就默认作为交付预览。保存、搜索和 HEAD 比较等操作只在当前文件支持时显示；保留既有显式比较与预览资源隔离边界。

同一个文件在同一工作区查看会话中只保留一个标签，再次打开聚焦已有标签。入口不再决定使用产物列还是独立编辑器。

Office 预览已提供 25%–300% 缩放、放大／缩小和适合窗口；PPTX 默认单页查看，支持连续查看、上一页／下一页和方向键／PageUp／PageDown。单页适合窗口同时约束宽高，固定比例放大后可以滚动查看；缩放不写回文档，也不提供直接编辑。中英文控件跟随应用语言。窄面板工具栏可横向滚动。

PPTX 主画布、缩略图与窄工具栏共用低对比圆角滚动条：原生横纵拖动区域为 10px，滑块用透明内边距收窄至约 4px；轨道与交叉角透明，去掉两端箭头，悬停与按下时增强对比，高对比模式使用系统颜色。继续使用浏览器原生滚动与拖动，不增加自绘滚动状态。`office-preview-controls.spec.ts` 的真实引擎回归通过，放大与连续模式截图位于 `artifacts/office-scrollbars`；触达源码 ESLint 通过。滚动条调整未重新打包桌面应用。

OfficeCLI 页面经只监听本机的 HTTP 代理追加查看控件，保留资源、选择 API 与 SSE 的同源转发；代理随 watch 最后一个租约释放、启动取消或崩溃关闭。代价是每个活动 watch 多一个本地监听端口，控件依赖固定引擎版本的幻灯片 DOM 结构；升级 OfficeCLI 时需重跑真实引擎测试。缩放和页码目前保存在预览页面内，重建预览后恢复默认值，未宣称跨宿主保留这两项状态。

### 打开位置与模式

默认使用内嵌形式。终端右侧 Island 与文件树的文件打开动作，包括已有点击、双击或右键菜单打开，均经同一打开入口处理；本设计不增加或改绑手势。当前模式决定后续文件的承载位置：

| 当前状态 | 打开文件的目标 |
|---|---|
| 尚未建立文件查看会话 | 创建内嵌区并打开文件 |
| 当前为内嵌 | 在内嵌区新增或激活标签；已收起则重新展开 |
| 当前为浮窗 | 在该工作区已有浮窗新增或激活标签 |
| 浮窗最小化 | 恢复浮窗并激活目标文件 |

模式按工作区隔离，在当前查看会话内持续有效。项目 A 的浮窗模式不改变项目 B 的默认内嵌行为。浮窗完全关闭后，该工作区下次打开文件重新默认内嵌；不要求跨应用重启持久化浮窗偏好。工作区与 worktree 的具体身份解析须沿用既有编辑器范围边界，不能为合并窗口而串用不同根目录。双击打开的内嵌区按工作台动效语言展开：文件窗口网格轨道与 DOM 槽位常驻（关闭时留 0px 空壳占位，否则网格自动排布会把右侧工具区挤进错误轨道，出现黑区与悬浮卡错位），打开经 240ms 网格过渡平滑撑开并伴随内容淡入；减少动态效果偏好时直接显示。

### 内嵌与浮窗切换

“浮出”和“嵌入”迁移整个工作区文件查看会话，包含全部标签与当前激活项。切换成功后同一会话只有一个活动宿主，后续所有打开动作跟随它。保留未保存内容、每个文件的源码／预览模式，并尽可能恢复光标、滚动与预览缩放。切换不强制保存，不以重新读取磁盘替代草稿迁移。

目标宿主接收状态成功后再隐藏或关闭源宿主；迁移失败保留原宿主与草稿并提供错误反馈。OfficeCLI 预览租约及 HTML 资源租约必须明确交接或重建，避免源宿主卸载过早释放目标仍需使用的资源。迁移期间到达的文件打开请求也须进入最终宿主，不能重新创建另一套标签。

### 控件与关闭语义

内嵌时不显示左上角关闭、最小化、最大化等窗口控件，也不保留其空白占位；保留文件标签、适用的文件操作，以及“浮出”和“收起”。浮窗才显示原生窗口语义的控制、置顶与“嵌入”。文件标签关闭按钮在两种形态中均可用。

收起内嵌区保留挂载的内容、标签、草稿和模式，禁用隐藏内容交互；右侧固定入口或再次打开文件恢复。恢复与空间协调见[辅助面板控件](./requirements/auxiliary-panels-preview-controls.md)。迁移、浮窗置顶位于更多菜单，收起使用独立面板图标；标题行与文件操作行分层，窄宽下查找／比较进入更多。关闭标签按文件处理未保存内容；关闭浮窗按整个会话处理未保存内容。保存失败或用户取消时保留文件和宿主。完成浮窗关闭后结束本次浮窗路由；再次打开默认内嵌。保存、放弃与取消沿用现有应用主题确认流程。

### 终端右侧 Island 的边界

保留本轮与历史文件改动入口；历史记录打开的是当前文件，不承诺还原当时版本。文件系统快照可能包含同工作区其它写入，不将记录描述为该终端独占生成的成果。右侧 Island 在当前聚焦终端收到非空文件改动后自动展开最近列表，6 秒后自动收起；鼠标悬停或键盘焦点在岛内时暂停计时，离开后重新计时。手动展开同样遵循该计时，点击外部立即收起，Esc 与收起按钮也可关闭。窄于 240px 的终端面板保持收起。此交互已单独实施，不代表本文其余统一窗口设计已完成验收。

## Alternatives considered

保留两套文件窗口并只统一配色和控件，改动较小，但标签、草稿和后续打开位置仍会分裂。由每个入口分别选择内嵌或浮窗，能保持局部灵活性，却延续用户记忆入口差异的负担。只迁移当前标签可以支持并排查看，但会形成同工作区双宿主，使“后续点击跟随当前模式”变得含糊。

完全移除浮窗最简单，但丢失多屏、置顶及独立查看能力。维持现状可复用所有链路，却保留重复提醒与相同文件不同去向的问题。因此选择统一文件会话与打开路由，保留两种宿主。

## Consequences

实现需要收敛产品预览与编辑器的文件状态和打开路由，共用内容与外壳；无需为了界面统一而替换 OfficeCLI 引擎。涉及顶部 Island 产物入口退役、文件树与终端打开入口、内嵌布局、原生浮窗管理，以及草稿、文件监听和预览租约的跨宿主生命周期。

内嵌区的精确位置、宽度下限、窄窗策略及与右侧工具面板的空间分配尚未确定，实施前结合现有布局补充，不承诺同时新增分屏或多浮窗能力。后台文件变化应继续刷新安全可刷新的预览；未保存草稿不能被磁盘事件覆盖。

## 待验证行为

实施后应验证两处入口默认内嵌，切为浮窗后所有后续打开都进入已有浮窗，重新嵌入后恢复内嵌路由；同文件标签复用、浮窗最小化恢复、项目与 worktree 隔离、收起重开和浮窗关闭后的默认回归均符合上述规则。

还需验证多标签双向迁移不丢草稿与当前状态，迁移失败和迁移中打开文件不会产生双宿主，Office／HTML 预览资源正确释放或交接，保存失败和取消不会关闭内容，以及内嵌没有窗口控件而浮窗保留窗口能力。顶部 Island 不再出现产出提醒或产物跳转，右侧本轮与历史入口及文件树查找仍可用。

统一文件窗口的功能验收尚未完成；右侧 Island 自动展开与收起的独立验证见[终端右侧 Island 轮次历史](../terminal/terminal-right-island-turn-history.md)。

Office 控件最终定向复跑额外覆盖 340px 窄 iframe 下的适合窗口与翻页、连续滚动同步页码，通过；输出位于 `artifacts/office-preview-controls-final`。类型检查、应用构建和 Note 检查通过；触达源码 ESLint 无错误，watch pool 保留既有 `prefer-const` 警告。完整桌面应用与打包验收未执行。
