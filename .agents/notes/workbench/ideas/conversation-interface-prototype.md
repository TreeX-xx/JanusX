# 普通对话与 SuperAgent 共用界面原型

## Intent

用户要求用可交互 HTML 评审对话界面，并明确后续落实到 **dev 和 superAgent 两条分支**，覆盖普通界面的对话模式与 SuperAgent。完整界面的评审入口为[离线 HTML](../../../../design/superagent-conversation/SuperAgent%20Conversation.html)。2026-11-13 已将 SuperAgent 全屏加载的 JanusX 字标与扫描效果，以及项目区底部用量栏的圆环、覆盖式统计接入真实组件；两种模式的输入框与发送／停止布局也已同步，其余原型调整尚待实施。顶部“界面”切换两个外壳，场景、主题与设计说明用于评审；不作为未来产品导航。

本 Note 是这版原型的交互记录与后续接入入口；既有生产事实仍归[终端与对话双模式](../terminal-dialog-dual-mode.md)及[SuperAgent 界面](../../agent/superagent-interface.md)。旧 `superagent-bubbles` 多输入原型拥有独立历史，本版不覆盖其记录。当前原型工作树为 `feat/superagent-automation-exploration`；“superAgent”记录用户指定的目标线，实施前再核对实际 Git ref，本次未切换或合并分支。

## 已确认的交互约束

| 区域 | 后续两条分支需要保持的行为 |
| --- | --- |
| 当前执行计划 | 保留现有输入框上方的完整步骤、进度和开合方式，只适配 UI。运行默认展开，完成默认收起；用户明确展开/收起的选择优先于状态更新，完成后仍可查看最新计划。 |
| 历史与文件 | 历史计划版本与“本次修改文件”跟随所属回复，按需展开；不把历史计划列表常驻在底部。文件归属使用真实轮次身份，不能把整个工作区 Git 变更当成本轮修改。 |
| 输入控件 | 保留当前模型切换、六格信号式推理强度及闪电快速模式。模型搜索、选择和能力禁用沿用真实引擎；不用新图标替换信号格。 |
| 发送与停止 | 未运行仅发送；运行中无草稿仅停止，有草稿时右端发送补充、左侧弱化停止。停止保留草稿，发送补充后恢复单个停止；生产接入保留既有 steering 和回执语义。 |
| 阅读定位 | 左侧轮次刻度/定位标记保留预览与点击跳转，并标识当前位置。跳转最下方只显示箭头，保留悬浮说明和可访问名称。 |
| 上下文入口 | 改在既有底部运行状态折叠栏，输入框附近不再重复。18px圆环中心留空，用占用弧段表示进度，右侧常驻百分比；悬浮/聚焦/点击查看用量明细。 |
| 底部统计 | 保留向上覆盖展开的方式。展开、收起、更多统计和面板内滚动均不能挤压上方对话、移动输入区或改变上方阅读位置。卡片尺寸、内容与交互需要一并改善。 |
| 品牌与强调 | 固定品牌点缀，移除强调模式切换与旧偏好读取；选中项、当前步骤和主操作仍要有明确中性色强调。语义状态和推理等级颜色保留。 |
| 新对话与身份 | 移除初始输入区下方三个建议入口。SuperAgent 回答左侧继续使用 Janus 双眼；普通对话沿用当前引擎形象。 |
| 加载 | 保留当前满屏数码方块波场、灰阶与右下布局、文案及等待条；字标参与扫描显现，不改变加载结构。 |

## HTML 当前交互

### 消息、计划与输入

正文开放排版，用户输入右侧气泡；执行过程默认折叠，摘要持续显示当前或最近的工具/命令、状态、操作数量与耗时。运行、等待、失败和中断均不强制展开，手动开合跨更新和完成保留；单项工具日志、历史计划和文件列表分别按需展开。等待授权的命令显示未执行，中断项不显示成功结果。此映射对照本地 WorkDisclosure、Janus ChatTimeline 与 conversation-output，可由真实工具事件驱动，无需额外模型调用；HTML 仍使用预设事件数据。当前计划固定在输入区上方，手动开合状态在原型重绘及完成后保留。文件查看器支持文件切换、统一/并排 diff、路径复制及选中代码引用。附件在光标处插入，保留原草稿；文件搜索有空结果反馈。这些都是内存演示，后续接入已有引用序列化与真实文件来源。

用户提出其他跳转样式后，明确决定保留现有左侧轮次标记，未实现替代导航。原标记悬浮/聚焦预览，点击定位；上翻阅读时保持位置，回到最下方按钮为单箭头。两种界面同步移除左右两侧的新对话、搜索、收藏及对应快捷键；左上角统一使用 JanusX 字标，历史入口继续可操作。Enter 发送、Shift Enter 换行；弹窗支持 Escape 并归还入口焦点。

强度使用六格递增信号，横向选择器支持左右键、Home/End、Enter；模型菜单支持搜索及键盘选择；选中项仅使用整行中性底色和字重，移除左侧高亮和对号，保留 aria-selected 语义。切换到不支持当前强度的示例模型会回退，快速模式不支持时禁用并解释原因。生产必须沿用各引擎真实能力，样例模型名、强度范围和回退值不作为产品配置。

演示包含新对话、执行中、已完成、待授权、待回答、失败、中断及 SuperAgent 全屏加载。允许/拒绝、问题选项和文字补充、重试、停止/继续均有状态变化。失败和中断保留实际演示进度，未完成步骤不补成完成。运行中补充队列可取回或删除，**该队列仅为样例呈现，不得覆盖 SuperAgent 已有即时 steering 和消费回执语义**。

输入文字区与底部工具栏之间保留1px弱灰分割线，比外边框更淡；两端与输入文字留白对齐，普通对话和 SuperAgent 共用。颜色取边框色85%与表面色15%混合，随深浅主题适配，聚焦和运行时保持同色、不加阴影。新会话左右内缩桌面19px、窄窗14px，已有会话为17px/13px；装饰线不占布局空间，不拦截点击。HTML 保留上述新会话留白；生产两种输入框已同步弱灰分割线，使用现有主题令牌，左右内缩统一为桌面17px、窄 pane 13px。

发送区按状态收敛：未运行时仅显示发送（空输入时禁用）；运行中无草稿时仅显示停止；运行中有草稿时右端显示发送补充，左侧出现弱化的停止按钮。主按钮保持右对齐，停止保留未发送草稿，发送补充后恢复单个停止按钮。普通发送与运行中补充统一使用向上箭头，通过提示区分操作含义。这里的停止是中断执行，不表示可恢复的暂停。这项已确认方案已接入真实 AgentComposer 与 SuperAgent 根输入框，沿用现有取消能力、命令与投递守卫；SuperAgent 保留上下文及 # 引擎 / @ Worker 操作，不加入推理强度。

### 底部覆盖式统计

2026-11-13 已接入当前 checkout 的 TerminalArea / TerminalUsageDetails；生产沿用“用量”名称、28px底栏、终端会话真实数据及调高能力，卡片主区保留累计缓存写入等现有统计。接入的是既有项目区底栏，不移动全局工具布局，也不补造 Janus/DSH 原生用量。生产当前设计与验收归[底部用量栏](../runtime-drawer-cards-resize.md)。

底栏保持原有高度，展开面板绝对定位于其上方。桌面面板上限为 min(440px,60dvh)，三列卡片，内容区最大1320px，间距12px；容器宽度不超过1000px改两列，不超过600px改单列。卡片15px内边距、11px圆角；1440px桌面约380px宽，避免单卡无约束拉宽。以上尺寸为当前提案，核心约束是容器适配与不挤压上方。

运行状态按钮、底栏空白及会话数量均可开合。圆环独立查看详情，不连带切换面板。展开使用180ms淡入/轻位移；收起期间立即禁用焦点与指针，结束后隐藏。连续快速开合取消旧定时器，避免已打开面板被旧回调隐藏；减少动态偏好关闭过渡。

关闭按钮或 Escape 收起并把焦点还给运行状态按钮；点击外部或焦点离开则收起且不夺取新焦点。圆环详情优先响应 Escape。面板内滚动不会带动上方对话，标题和关闭按钮在面板内吸顶；每次重新打开从统计顶部开始，避免尺寸切换后卡片标题被旧滚动位置遮住。卡片“更多统计”分别开合，在同一原型状态内保留。展开时耗时局部刷新，不重建卡片或丢失焦点。

每张卡包含引擎/模型/状态、上下文已用/窗口/外置百分比和进度条、输入、输出、缓存读取、命中率、累计用量、压缩次数、工作区及耗时。“更多统计”提供剩余、实际窗口、示例模型容量与缓存写入。当前会话卡用中性短竖线标记；圆环详情与当前卡共用数据来源，详情补充输入输出、缓存和压缩信息。

原型中的三张卡与所有数字均为 fixture。窗口占用与累计消耗分开展示；缓存命中/累计用量公式仅为示例，未来按既有用量数据及引擎口径映射，缺失、不支持和未知不得伪装成0或已完成。不要新增演示会话、硬编码真实模型容量，或由此推断计费。

### 双界面与视觉提案

普通对话保留引擎身份、终端/对话切换；HTML 中终端是可返回的静态展示，不重启或创建会话。SuperAgent 保留 Janus 双眼与执行侧栏。两种外壳共享样例用于比较，生产仍分别绑定真实会话。

本轮 HTML 将已获用户认可的 CODEX 切角字形扩展为8款字标：JanusX、Codex、Claude、OpenCode、Pi、DeepSeek（DSH）、Shell、Janus。终端名称依据 src/shared/terminalLaunch.ts，原始轮廓集中在 wordmarks.mjs；build.mjs 生成各自 SVG 与可切换的 Wordmark Family.html。各款共用64单位字高、12单位笔画和切角收口，短词保持自然字宽。JanusX 使用同家族切角轮廓，X 从右上到左下的完整斜笔保留浅杏橙，导航宽132px；用于两种界面的导航、SuperAgent 空态和加载。用户进一步确认新版 JanusX，现已同步到生产加载资产，复用既有扫描与布局；其余终端字标尚未同步生产。Tab、终端选择和启动入口保留现有图标，Janus 回复头像不变。两种模式的新会话共用 welcome.css 与等高身份容器，身份、标题、说明、工作区提示及输入文字左对齐。普通对话移除顶部重复的引擎图标、名称及项目路径，终端／对话开关并入标题栏右侧；新会话使用 `assets/codex-wordmark.svg` 定制大写字标，五个字母均为独立路径，没有文字节点或字体依赖。C/O/D 共用切角轮廓，E 的横画斜切收口，X 以留白区分交叉笔画；桌面/窄窗/矮窗宽190/170/151px，深浅主题分别使用正文中性色。原引擎图标保留25px、窄窗23px。SuperAgent 使用同家族 JanusX 字标，宽231/206/183px。标题统一为“想从哪里开始？”，说明统一为“聊一个问题，或从项目文件开始。”；工作区使用无胶囊底色的轻量文字。两种外壳的空态顶部总占位和内容间距一致，切换模式时标题与输入框保持原位。回复、Worker及底部统计的小尺寸引擎名称继续使用较轻的 Cascadia Code，回退 Cascadia Mono / Consolas。界面改为暖石墨灰/柔白，正文15px，卡片和输入框适当柔化。固定品牌点缀下，导航选中项保留细竖线；当前运行的工具/命令与计划步骤均移除左侧竖线，使用整行底色、字重和状态文案高亮，主要操作使用高对比实心按钮。强调模式切换入口与变体样式已移除。CODEX 与新版 JanusX 切角字形已获认可，其余新增字标与精确尺寸仍属**待评审提案**；详见[视觉规格](../../../../design/superagent-conversation/brand-spec.md)。

数码加载的原有构图保留。字标先显示低亮底形，再由左至右扫描填充，最后显现完整橙色 X；减少动态偏好直接显示完整字标。扫描和波场共用可见计时。HTML 为评审至少呈现2600ms后淡出420ms，隐藏页面暂停可见时长，切换场景会取消旧加载。本 checkout 已接入的生产加载继续由真实 persistenceReady 与可见计时共同控制，并保留减少动态偏好跳过视觉等待的既有规则；不要把 HTML 固定演示时序或状态文字当成后端阶段。

## 两条分支的后续落实范围

| 范围 | dev | superAgent |
| --- | --- | --- |
| 共用对话 | AgentSessionPane / AgentComposer 及共享计划、文件、引用、定位和用量组件接入同一套视觉与交互。 | 复用同一套公共组件/令牌，适配 Janus 对话宿主；不复制另一套长期分叉的控件实现。 |

| 行为与数据 | 保持真实轮次、停止/审批、文件归属、会话恢复和引擎能力。 | 保持现有 steering、工作调度、命令流、报告、权限和恢复语义；本提案不调整协议。 |
| 验证 | 在真实普通对话组件验证计划手动状态、模式切换、控件能力、底栏几何和窄窗。 | 在真实 Janus/Worker 宿主验证相同共用规则，并验证头像、数码加载和实时数据更新。 |

后续实施以真实组件为入口，映射主题语义令牌，逐分支维护当前事实与验证记录。HTML 的评审工具栏、模拟任务、固定三会话、演示用量/模型目录、文件补丁、测试计数及自动完成定时器不进入生产。两条分支的接入完成状态分别记录，不能凭其中一条通过而宣称两条完成。
