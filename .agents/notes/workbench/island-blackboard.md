# 灵动岛下拉副黑板：卷帘格局、钉住语义与借调规则

## Problem

下拉拖拽手势（`src/renderer/src/components/janus/useIslandGesture.ts`，≥60px 阈值、弹性过阻尼 0.4/0.15、pull-hint 跟随）当前绑定 `setBlueprintMode(!blueprintMode)`（`JanusIsland.tsx` 的 `handleSwipeFlip`），把中央工作区整张卡片翻面到蓝图视图；`design/janus-island-hifi.html` S0 手势总表也把「下拉拖拽 ≥60px」定义为「翻转蓝图视图（flip）」。三个问题：其一，翻牌是一卡两面的互斥隐喻，看蓝图时终端区整体消失，参照与工作不能同屏，恰好加剧「所有东西挤在一个面板」的痛点；其二，蓝图入口冗余——`blueprintMode` 翻牌与右上 `WorkbenchSwitcher` 的 `activeWorkbench: 'blueprint'` 两套机制抢同一块地，动画语义分叉（`flipDuration`/`dragFlipProgress` 对工作台开关）；其三，翻牌有真实布局代价，`BrowserSurface` 在 `blueprintMode`/`isIslandDragging` 下要整体藏现原生视图。

## Decision

下拉手势改绑**副黑板（副工作区）**：岛胶囊下拉 ≥60px，**中部工作区下滑让位**——板在中央工作区列的上带长出（高 220px～70vh，默认 420、下缘可拖），工作区是动画主体、随拖拽跟手下滑，不是从顶部盖下的卷帘。

**格局取「中央列 + 工作区下滑让位」**（2026-10-17 修订，取代首版切片的整窗宽覆盖卷帘）。三条边界：其一，板只占**中部工作区列**，左右栏架（侧栏、右坞/工具轨）全程可见可点——整窗宽覆盖会埋掉工具轨入口，且与「从文件树拖钉上板」的钉入口自相矛盾（操作面不可遮，内容面让位）；其二，动效主体是**工作区下滑**（下拉预览跟手、松手落点），岛胶囊本体不动，旧「岛跟手弹性下滑 + 工作区 rotateX 翻转预览」一并移除；其三，让位在拖拽中即时跟手（与右坞拖宽同语言），pty/原生视图几何随 flex 收缩自然结算——工作区容器变矮后浏览器原生视图 bounds 跟随矩形缩，不再需要板缘裁剪。板下缘 1px 发丝线作天际线；收板走下缘上推（低于 220px 落零）、收起按钮与 Esc 分层。

**判据取中断代价，不取能否交互**。收起时可 reload、可恢复的内容（原型、报告、预览）随便交互；中断有代价的内容（跑着的进程、未保存编辑、会话上下文）不上板。早期「黑板永不持有键盘输入」的规则作废——它与展开岛 chat composer 已收键盘输入的事实矛盾，且误伤交互原型这一核心场景。

**板面内容（2026-10-17 三次修订）**：板面**只承载复用蓝图界面**——`BlueprintView`（workbench 密度，不渲染嵌入聊天）直接落在板上：画布节点可交互点击查看，左侧详情槽（`BlueprintDetailPortalContext` + `bp-node-detail`，复刻工作台左列）常驻显示内容，**不带右侧对话**；蓝图载入后默认选中根节点展开左列（画布既有行为）。文件钉（html/md/text）功能**整体移除**：钉入口、钉 store（`janus:blackboard-pins`）、跟随文件 watch、打开真身一并退役；下面的三种钉分类降级为未来扩展的判据记录，不再是当前交付。

**三种钉（规划分类，当前交付不含文件钉）**：

| 钉型 | 内容 | 语义 |
| --- | --- | --- |
| 投影钉 | 蓝图活图（默认页签）、md 钉读、html/localhost iframe | 真身留工作区，板上是分身，双视图并存；收板卸载即可 |
| 借调钉 | 真浏览器 tab | WebContents 唯一实例换宿主矩形，工作区留占位卡；收板插值归还。iframe 盖不住通用网页（X-Frame-Options / CSP frame-ancestors），真网页只能借调 |
| 终端 | —— | 出局：不设交互终端，也不设输出 tail；盯输出走展开岛 monitor 与 RunOrb |

判定规则一句话：能造出廉价分身的走投影，造不出的走借调；两者都保证收板无代价。借调目前只有浏览器一个成员，规则通用——未来原生视图类内容（如 PDF 阅读器）直接套用。

**交互（2026-10-17 三次修订）**：岛胶囊下拉 ≥60px 为 **toggle**——板未开则放下，板已开则同一手势再下拉**自动回收**；pull-hint 文案随开合态翻转（放下 ↔ 收起）。收板另有**图标式收起控件**（板头 ChevronUp，透明底 + 1px 发丝线，无文字钮）、板下缘上推与 Esc 三层。单击 peek、双击控制台、下拉黑板各自独立；启动已移到[顶栏运行按钮](run-orb-budding.md)，不再使用长按，expanded 下复杂手势仍禁用。板内布局=左详情槽 + 画布（复用蓝图界面，无右侧对话），不做自由拖窗（避免长出第二棵 pane 树）；板面交互全部继承蓝图画布（点选节点开左列、搜索/筛选/fit 等画布工具栏原样可用），遵守无色块与四级排版纪律（[运行配置分体卡片](./run-config-island-cards.md)的令牌管道）。焦点与 Esc 分层：收板走上推手势、图标控件与 Esc；焦点在 iframe 内 Esc 归板内页面。借调 v1 限单槽留待未来；动画期原生视图走 freeze-frame 皮（`0770929` 已有），拖板高逐帧 setBounds；原生视图直角限制被「工作区直角加发丝线」纪律天然掩盖。

**入口收敛（2026-10-17 已完成）**：`blueprintMode` 翻牌路径整体退役——翻转卡正反面（`BlueprintFocusView`）、`flipDuration`/`dragFlipProgress`/`isIslandDragging` 与 App 的 perspective 旋转预览全部移除；蓝图完整入口只留右上 `WorkbenchSwitcher`（`activeWorkbench`），一入口一语义。蓝图是黑板的唯一内容（复用蓝图界面，三次修订起），通知动作（打开蓝图/打开维护）可就地落到黑板。

## Alternatives considered

- 继续下拉翻牌放蓝图——最强理由是零改动且保住初衷。否决原因是互斥隐喻与双入口冗余正是痛点根源；问题不在蓝图内容，在「一面一内容」的格局。蓝图该做黑板默认内容，而不是手势的全部目的。
- 黑板做第二棵 pane 树、收交互终端/编辑器——最强理由是副工作区名副其实、真缓解 pane 拥挤。否决原因是两个焦点域、拖拽落点、快照恢复与 pty resize 全套成本，且卷帘可随手收起的自由会被「收起即打断工作」毁掉，痛点翻倍。
- 预览一律禁止交互——最强理由是保住零键盘输入不变量。否决原因是设计工作流的核心产出就是可点交互原型，不能点的原型等于截图；判据改为中断代价后不再需要这条禁令。
- iframe 冒充通用浏览器——大量站点 X-Frame-Options/CSP 拒绝嵌入，不可靠；本地页与 localhost 由 iframe 覆盖，真网页走借调。
- 整窗宽覆盖卷帘（首版切片的默认）——最强理由是手势最省事、宽原型铺得开。否决原因是顶带会埋掉左右栏架：工具轨入口被盖住后「边看板边干活」不成立，且文件树被盖住时「拖钉上板」做不出来；宽内容留给槽位内部排版（md 钉读加阅读最大宽度）。
- 「覆盖不取让位」的旧取舍（几何稳定优先）——最强理由是瞥一眼节奏下 pty 不该抖。否决原因是它只在整窗宽覆盖的前提下成立；板限中央列后，工作区下滑让位的结算随 flex 收缩自然完成，拖拽跟手与右坞拖宽同语言，瞥一眼的开合成本可接受。
- 黑板改侧搭右列——最强理由是完全不遮工作区。否决原因是从顶部岛下拉的手势语义指向纵向卷帘，侧向属于右坞已有的另一套手势与布局语言。
- 终端给只读输出 tail 作为折中——用户明确砍掉；盯输出的需求由展开岛 monitor 与 RunOrb 承接，黑板边界因此更纯。

## Consequences

落地面：`useIslandGesture` 回调从 `setBlueprintMode` 改落板 toggle 语义、板 chrome 与左详情槽 + 画布槽位、`BlueprintView`/`BlueprintDetailPortalContext` 复用、`blueprintMode` 收敛。视觉遵守 planche 纸底墨线、透明面板加 1px 发丝线、无色块填充（选中=文字+2px 强调条）与四级排版层次（[planche-theme](./requirements/planche-theme.md)）；板内蓝图界面沿用自身材质（复用优先于换皮）。`design/janus-island-hifi.html` S0 表「下拉拖拽 ≥60px → 翻转蓝图视图（flip）」一行由本决策取代。

修订条件：出现「板上要敲命令」的持续证据→重启终端议题（当前明确拒绝）；用户长期开让位模式→常驻共存改道工作区分屏，而非继续拧卷帘；出现第二个原生视图类内容→直接套借调钉规则；文件钉需求回归→按三种钉分类重启，不走旧 `janus:blackboard-pins` 实现。

**落地状态（2026-10-17 三次修订后）**：手势为 toggle——下拉 ≥60px 落板/再下拉回收，拖拽预览跟手（`blackboardDrag`，仅未开时），松手落点到持久化高度；板是 `main` 的 flex 首子（中央列上带），工作区容器 `flex-1` 下滑让位；板面=复用 `BlueprintView`（workbench 密度，无右侧对话）+ `BlueprintDetailPortalContext` 左详情槽（载入默认展开根节点），板头仅标题与图标收起控件（ChevronUp）；下缘 9px 拖高（低于 220px 上推收板）与 Esc 分层保留；翻牌路径已退役（见入口收敛）。板高持久化 localStorage；文件钉（`janus:blackboard-pins`、跟随文件、打开真身）及其持久化已随三次修订移除。未做：借调钉、文件钉（明确移除，回归走修订条件）、收起/落板的过渡动效打磨。
