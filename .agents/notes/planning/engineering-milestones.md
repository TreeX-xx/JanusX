# 工程排期里程碑备忘录

## 线性里程碑

### 092 节点（v0.9.2）

- **备忘录**：Chat 联动备忘录与线性里程碑，支持对话自动整理、人工直接编辑、右侧悬浮查看与工作区映射。
- **shell功能扩展**：扩展终端与 Shell 执行环境能力，增强交互操作、执行控制与命令集成。
- **工具界面提升**：优化工作台工具区域、运行抽屉与卡片式交互体验，提升工具可用性。
- **界面小改**：细节 UI 微调、状态指示对齐、间距留白与主题视觉一致性优化。
- **用量统计**：完善原生会话用量统计、Token/耗时记录持久化与紧凑用量面板呈现。

### 093 节点（v0.9.3）

- **远程基座**：公网连接基座与远程协作通信能力，支持跨网络终端输出显示、输入交互与状态协同。
- **docker（基础）**：基础 Docker 容器管理能力与工作台管理入口（配置地址、快捷打开及基础状态）。
- **http（基础）**：建立基础 HTTP 协议服务层与外部 API/Web 通信适配能力。

## 未归入节点

## Intent

维护 JanusX 工程排期的线性里程碑备忘。作为工程计划与主线节奏的对齐凭据，以自然语言的点记录各版本节点的核心事项；不设硬性完成状态字段，随对话与工程推进持续维护和演进。

## 维护原则

- **线性顺序独立**：节点按工程计划先后表达组织顺序，不按版本号或时间自动计算间距。
- **无状态字段**：节点与点不维护完成状态等字段，通过对话就地调整、补充或归档。
- **动态归入**：未明确归属的散点先记录在「未归入节点」区，后续由对话或人工归入对应版本节点。
