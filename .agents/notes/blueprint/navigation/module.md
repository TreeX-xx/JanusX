# 模块投影与导航

## Responsibility

将共同 Note 来源投影为模块页，维护模块与文件布局、单击预览、双击进入、搜索定位和返回历史。布局与选择属于本机视图，不成为文档关系真源。

## Design

工作台首次打开时默认收起 Janus 对话栏，优先呈现正文与画布；点击 Janus 入口、起草或建议修复交接时再展开第三列。顶部工具栏常驻搜索、状态与类型筛选、适应画布、节点详情和数据来源；未关联根节点切换、恢复布局、撤销恢复及保存状态收进“更多”。浮层支持键盘、Escape 和外部关闭；保存失败仍在工具栏直接提示。工具栏和 Janus 入口使用主题中性底色、细边框及统一紧凑控件，减少重复身份与装饰强调。

插件迁移沿用原全屏卡片布局，覆盖主界面顶栏；插件通过通用 views.workbench.frame 契约绘制原第一栏的项目选择、更新／建议、审核活动、Janus 和关闭按钮，宿主执行经过授权的关闭／切项目请求，不再叠加标题卡。第二栏保留搜索、状态／类型筛选及画布控件，设置、刷新和历史导航收进“更多”。左侧标题固定、正文独立滚动，右侧固定 Janus 标题和底部输入区，中间滚动显示讨论与修改预览。来源诊断在第二栏弹层，更新／建议／自动审核在第一栏弹层，展开不改变画布位置；初始化或来源异常且无图时仍保留可见诊断。图数据更新保留同 ID 节点已测量的尺寸，避免设置遮挡及返回后节点持续隐藏。首次读取保留骨架屏与画布加载动画；卡片使用原 180ms 间隔／260ms 时长，节点按原 CSS 索引依次显现，关闭按 60ms 反向错峰并遵循减少动画设置。右侧采用原最简输入框，模型与维护范围折叠，讨论业务继续运行于插件。左侧已恢复原目录、章节折叠、关联预览及正文前折叠审核卡；更新／建议恢复原搜索、模块筛选和上下篇列表。加载态的来源诊断同样收进工具栏。原文操作与宿主聊天渲染仍有迁移差异，实际范围及验证由[官方插件专项](../../planning/blueprint-official-plugin.md#已确认的迁移回退与首次加载故障)维护。

中部画布沿用原模块卡片、文件分组、连线和浏览条，恢复 24px 点阵、主题对应背景、0.05–4 倍缩放、底部图例、空模块提示和右键节点详情；模块页不显示 React Flow 默认缩放按钮及缩略图，非模块图在不超过 250 节点时保留原缩略图。模块适配最高 1 倍、padding 0.2，左右卡片改变可用空间后等待尺寸稳定再适配，避免节点裁切；同范围选择不重复重放旧视口，以免覆盖随后的缩放。单击重新打开左侧正文阅读，双击以第一次点击的节点为准，避免阅读卡展开引发布局移动后进入错误模块。模块返回仍恢复历史选择和视口。

左上角按项目和 worktree 切换显示，工作树来自宿主当前 Git 列表，聚焦时重新读取；主工作树有单独标记，只有一项时不可切换。1.0.5 声明 views.workbench.rebind，在已授权工作区和 worktree 间切换时保留原生页面及顶栏，只清理并重新加载目标根的正文、画布、建议、选择与持久草稿；内容卡片重新入场，顶栏不重播。切换期间取消旧请求、清理旧订阅与后台所有权，旧响应不能带入新根；未授权项目或不可用根仍撤销页面。没有 Notes 的工作树显示“未检测到蓝图 Note”和适用的初始化预览入口。接口和边界归[插件契约](../../workbench/plugin-contract-v1.md#p3-工作台与-island-契约)，验证归[官方插件专项](../../planning/blueprint-official-plugin.md#worktree-显示切换)。

每个 worktree 的蓝图独立维护，仅加载和修改该实际根内的 Note。相同 repoId／Note UUID 不会合并不同根的蓝图，也不联动修改兄弟工作树；维护任务、预览、建议处理和布局各自绑定根。切换使旧页面的请求失效，等待文件锁的旧确认在进入事务前取消；已经进入事务的写入仍按共享引擎语义完成于原根，不改写新选中的工作树。

蓝图保留现有模块页、原文预览与关系详情。用户已取消独立“关系图谱”展示：视图切换、全局关系投影、关系筛选与 1–2 跳邻域控件及其专用测试已移除，不作为待交付功能。原始 Note 的显式关系、现有画布连线和关系详情继续使用共同来源。此选择减少第二套浏览入口和交互状态；若未来有模块浏览无法解决的明确检索需求，再单独评估。

单根首页使用根模块页，当前模块保留为父节点，直属子模块和按类型分组的文件构成下层内容；更多层级继续进入。note_focus 的展示动作复用导航与视口，note_scope 和普通访问保持被动。交互与关注分别由 [行为与验收](requirements/module-browsing.md)、[行为与验收](requirements/module-focus-navigation.md) 维护；对话写入与审批见 [职责入口](../maintenance/module.md)。

[Note 状态显示](note-status-display.md)维护已实现的类型感知映射：生命周期、moduleState 与任务执行/验收证据分别解释，accepted 不统一显示进行中。原灯位只提示待处理审核意见；具体规则由建议管理模块维护。卡片只展示真实类型，移除旧投影类型及重复工作区标签；未读版本使用右上角“有更新”和菱形，缩小后仅保留标记，具体规则由下方更新专题维护。

[Note 更新提示与建议定位](note-updates-and-suggestion-navigation.md)已接入本机版本观察：首次完整接入静默建立基准，主动查看新版本后减少更新计数，支持当前筛选批量已读及 8 秒撤销；批量确认按点击时的选中目标校验，不因无关 Note 解析错误或缓存同步状态禁用全部操作。更新、当前建议、自动审核共用列表与按身份定位，自动失败可查看阶段和原因；自动结果按“审核完成／需要重试”筛选，完成记录保留最近两轮产生完整结果的批次，历史未完成报告迁入持久重试集合，重试项持续保留至完整恢复。提交次数与重试数量分开展示，更新/建议刷新来源视图，自动审核刷新轻量状态，分别显示忙碌反馈；15 秒超时后保留结果并允许重试，首次加载先显示当前分支已保存记录并后台校验，计数与列表共用数据，同步错误不清掉已有数字；切换节点不额外刷新整库列表，已读回执直接更新计数。修复后的持久化审核结果直接推送到共用建议状态，顶部数量、节点提示与左侧意见同步更新；建议 revision 防止旧读取恢复已解决意见。宿主写入直接更新该篇阅读版本，正文与节点按 afterHash 单篇交付，卡片只补读保存建议；各自展示同步与重试状态，后台恢复自动清除旧错误，完整来源对账不再阻塞修复展示。左侧审核摘要常驻正文前，收起只隐藏详细意见，页签工具栏保留紧凑定位入口，建议直达自动展开。手动活动优先反馈，显式已读直接提交已呈现版本；工作区目录/搜索移出阅读区，顶部搜索补充身份与路径，来源保留总数和结构诊断。工作台加宽左侧并等量收窄右侧，完成列表区分两轮及结束时间。首版含加载骨架、平滑视口移动、聚焦轮廓和减少动态效果；快速跳转支持返回模块、筛选、视口与阅读位置。读取版本和处理建议分别维护，仍不做递归模块汇总。验证与尚未实测的桌面边界由专题维护。

当前建议按本篇全部待处理意见交给 Janus 修复，整篇保留只读讨论，另支持原始结构修复。问题卡片转移至当前工作区右侧顶部，展示真实加载和复核状态；结果更新共用建议状态，失败与未解决问题保留，差异和版本校验撤销在卡片内完成。实现与验证由[建议定向修复](note-updates-and-suggestion-navigation.md#建议定向修复)维护。

整篇修复、右侧紧凑可查看卡片、独立内部修复会话与左侧审核整体布局已实施；未写入原因及实际写入 hash 进入持久终态，写入后补读并核对预览来源版本。详情提示按钮与有限续执行已接入，最多追加两次执行，保留分页进度和工具证据，实际写入后再复核。dev 长 Note 在 4096 输出额度下已隔离复现截断；额度解析现已改为完整自动资料优先，真实缓存读到 1,048,576 上下文与 65,536 最大输出，匹配不足时先更新目录，再支持双额度手动回退。历史目标未被本轮诊断写入。来源观察已加入 epoch 保护，避免覆盖更晚的宿主写入和已读确认；图谱旧 hash 跳过自动确认仍有缺口；真实模型证据、已实施范围与类型/记忆测试问题由[建议交接专题](note-updates-and-suggestion-navigation.md#整篇修复紧凑卡片与独立对话)维护。

分支加载与建议隔离是新增产品约束：蓝图按实际分支 Note 刷新，当前建议绑定相同项目/工作区及输入版本。两边共改 Note 后按最终内容重审，能取得的当前未处理项可辅助核对；已处理和被替代报告不留历史。具体规则由[审核专题](../maintenance/note-content-review.md#分支蓝图与建议隔离)维护。完整版本的自动化静默运行，在蓝图顶部活动区显示当前阶段/对象/进度，节点提示灯仍只表示待处理建议；Git 调度与活动区已接入，具体实测与剩余限制见实施基线。
