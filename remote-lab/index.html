第一步：选择测试方式

先在同一电脑上跑通流程，或者直接准备手机蜂窝网络测试。

连接成功 → 控制端登录 → 主机批准 → 操作测试。GitHub 登录成功只完成身份验证，不自动授予操作权限。

01 / 选择测试方式

本机练习，或手机公网测试

本机练习

同一电脑开两个窗口。验证登录、申请、批准和操作，不证明公网穿透。

公网测试

电脑用家庭宽带，手机关闭 Wi-Fi 用蜂窝网络。先完成下面的 HTTPS 页面准备。

公网准备：使用 Janus 手机测试页

  1. 手机关闭 Wi-Fi，用蜂窝网络打开 Janus 远程连接测试页，确认能看到控制端。
  2. 电脑下方已填好同一地址。填写 GitHub Client ID，再点击“生成公网邀请”。主机拥有者登录不是生成邀请的前置条件。
  3. 手机扫描新二维码，等待连接；在手机登录，回电脑批准，最后在手机运行操作测试。

保持电脑 helper 和主机网页运行；无需开放电脑端口。若手机无法打开静态页面，先检查该地址的网络可达性。

可选：下载页面，部署到其他静态网站

下载手机控制页 index.html。把文件上传到已有 HTTPS 静态网站，再更换下方地址。文件不含你的 Client ID 或本次邀请。静态托管只提供页面，终端内容经 WebRTC 直连。

填写网页地址，不是电脑 IP。本机练习可以留空；公网邀请必须有可访问的 HTTPS 页面。

高级网络设置 · 节点、STUN 与手动交换

候选公共节点，未承诺免费或长期开放。WSS 只传加密协商信息。

工具拒绝 TURN 配置，并记录实际选中的 ICE 候选类型。

登录配置 · 由开发者设置一次

Client ID 是这款软件的公开应用编号。正式产品会内置配置，用户无需填写。先测试网络时可以留空。

第二步：打开控制端

我没有 Client ID，怎样获取？

Client ID 是公开应用编号，不是密码。没有它也能先测网络。

  1. GitHub：打开 Settings → Developer settings → OAuth Apps，注册应用。测试主页可填写本机地址；填写一个属于自己的回调地址（Device flow 不使用该回调），勾选 Enable Device Flow，复制 Client ID。不需要填写或分享 Client Secret。
  2. Google：在 Google Cloud Console 配置 OAuth 同意页和测试用户，创建「Web application」客户端。Authorized JavaScript origins 添加本机页面实际 origin（推荐 http://localhost:41873）以及手机静态页面的 HTTPS origin，不含路径。复制 Client ID。仅需基础身份，不需要 Gmail / Drive 等权限。
  3. 编号填好后重新生成邀请。Google 编号会随邀请传给控制端；GitHub 设备授权和 Google 凭据验证由本机 helper 执行。

不填写编号时，对应真实登录项显示“未配置”，不会显示通过。供应商限流、审批及网络不可达会记录为实际问题。

可选：单独验证主机拥有者登录

这两个按钮验证电脑拥有者身份，不会生成待审批成员。测试成员加入，请在第二窗口或手机上登录。本实验的审批按钮由电脑页面持有，不要求先完成这个可选测试。

03 / 回电脑批准

待审批申请与成员

还没有控制端申请。先打开第二窗口或让手机扫码，并在控制端登录。

“未登录设备”表示连接已建立，登录尚未完成；验证身份后才可批准。本机拥有者登录不会在这里生成申请。

建议的验证顺序
  1. 先做本机对照。 创建主机，打开本机控制窗口，提交网络测试身份，在主机批准。测中文、重复请求、输出流和撤销。这只验证工具与协议，不能算跨公网通过。
  2. 再做真实跨公网。 将生成的 dist/index.html 发布到你选定的 HTTPS 静态托管，填写手机控制页面地址。电脑用家庭网络；手机关闭 Wi-Fi，扫码连接。记录网络备注并导出双方报告。
  3. 测断网、后台与节点失效。 控制端断开再重连，确认输出恢复；手机锁屏再返回；断开信令后继续传文本；主机撤销权限后尝试操作和重连。
  4. 最后加入真实登录。 注册 GitHub / Google 应用，关闭“允许网络测试身份”，分别完成真实登录和拥有者审批。将没有运行或失败的项目如实保留。
  5. 换网络重复。 不同运营商、另一条宽带、公司网络及第二台设备。公共信令或 STUN 失败都算方向选择的证据，不通过业务中继补救。
手机必须有可访问的 HTTPS 静态页面；本机 helper 只监听 127.0.0.1，不向公网开放。不要为了测试添加端口转发。所有公网使用条件需实测后再定生产方向。
