本次更新新增内置浏览器自动化控制、托管仓库侧栏与自动化卡片，并完善原生 CLI 对话、文件操作和运行状态展示。

## 更新亮点

- **内置浏览器控制**：接入 Chrome DevTools MCP，支持页面浏览、快照、点击、输入和截图；设置中可管理浏览器开关、超时、连接检测与停止控制。
- **终端浏览器接入**：为 Claude Code、Codex、OpenCode、Janus CLI、Pi 和 DSH 提供配置入口，支持接入、检测与移除。
- **托管仓库侧栏**：在工作台中集中查看和操作托管仓库。
- **自动化卡片**：集成自动化卡片与 Island 工作流，里程碑采用横向流程展示。

## 体验优化

- Claude Code 新增独立 Ultracode 会话开关，完善首次启动的工作区信任确认。
- 对话区增加当前操作预览，区分执行中、输出与完成状态。
- 文件引用保留行内阅读体验，Codex 文件引用显示为可读链接。
- 独立文件编辑器支持复制绝对路径和在文件管理器中定位文件。
- 自动化控制设置沿用现有主题与中英文界面；终端接入状态、配置冲突和检测结果集中展示。

## 问题修复

- 修复 Codex 异步问题的选项、自定义答案与原生问题状态同步，保留输入框草稿。
- 优化连接重试提示，恢复后清除临时状态，区分重试与最终失败。
- 改进 Codex 历史数据库编辑失败后的恢复，并修复并行终端与原生会话的关联。
- 修复工具输出和代码示例被误识别为图片的问题。
- 修复 Windows 下 Claude Code 启动时工作区路径大小写不一致的问题。

## 升级须知

- 浏览器控制需要 JanusX 保持运行；外部终端接入后可能需要重新连接或重启会话。写操作遵循 JanusX 的审批设置。
- “电脑控制”目前仅提供 Cua Driver 路径配置与版本检测，尚不提供桌面操作能力。
- Blueprint、CPA、Docker 与 Android 测试包可继续从 [v0.9.8](https://github.com/TreeX-xx/JanusX/releases/tag/v0.9.8) 下载，本次未重新构建这些附件。
- Windows 主程序未进行 Authenticode 签名。

## 已知限制

- 浏览器控制不提供任意 JavaScript 执行和性能采集；截图以文件路径返回，尚未接入模型图像消息。
- 外部 CLI 的内部权限模式与轮次状态不与 JanusX 自动同步。不同 CLI 的命令、审批和运行中追加输入支持范围仍有差异。
- Android 为局域网测试能力，Docker 插件仍为实验功能。
