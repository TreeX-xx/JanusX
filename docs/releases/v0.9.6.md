# JanusX v0.9.6

本版集中整理工作区数据管理、官方可选插件与设置体验，并移除已退役的功能。相较 v0.9.5，Blueprint 仍为 1.0.8。

## 工作区数据与升级

- 工作区私有状态改存应用用户数据目录，减少项目目录内的运行时读写。旧工作区通过升级提示或「设置 → 数据管理」主动迁移，可逐项预览来源、目标与处理结果，也可批量迁移符合条件的工作区。
- 新增工作区重新定位、失联数据恢复、日志及过期数据维护。解除最后一个工作区关联后，私有数据保留 30 天恢复期；未知文件保留，不按运行缓存自动删除。
- CLI Hook 改为每次启动独立注入；数据管理提供旧 Hook 的预览和主动清理。
- **终端与 Agent 自动还原点已退役。** 主动迁移会清理旧还原点及已迁入应用目录的副本；需要的历史内容请在迁移前另行备份。当前 Island 文件差异查看保留。
- 迁移处理应用配置与日志，不迁移项目源码、工程 Notes 或构建产物；暂不支持远程工作区迁移。

## 插件与界面

- CPA 拆为可选官方插件，不再作为宿主固定功能。
- 新增实验性的 Docker 官方插件，支持本机、已有 WSL 与专用 WSL2 环境入口，以及容器、Compose、日志、终端和服务访问。WSL 启动窗口与代理转发经过整理。
- 插件管理增加搜索、卡片和可折叠管理详情；设置中的数据管理按用途分组，迁移说明支持鼠标和键盘查看。
- 桌面通知等待内容绘制后显示，同步主题并处理连续替换，减少旧内容闪烁与透明窗口灰边。

## 历史功能移除

移除 Laya 运行资源与接口、旧产物工作区、旧知识库调用及界面、旧 Wiki 与知识卡片、旧任务执行界面。个人记忆、当前文件预览与任务执行后端继续保留；旧数据不会因此自动批量删除。

## 已知限制

Docker 插件仍为实验功能，真实引擎和完整公开交付验收尚未全部完成。工作区迁移已有本机隔离场景验证，正式安装器跨版本升级、物理慢盘与多日使用仍需补验。本次 Windows 候选包的启动检查不等同于这些升级和长期使用验收。
