# JanusX v0.9.7

本版重点完善终端的对话模式与输入体验，增加离线 PDF 预览，并改进首次配置和工作区界面。

## 终端与对话

- 完善 Claude Code、Codex、OpenCode 和 Pi 的终端与对话双模式，整理会话启动、状态和切换体验。
- 输入区支持跨会话输入历史、文件引用、图片附件与预览；对话中的图片产物可查看和复用。图片生成仍取决于所用 CLI、工具及账户能力。
- 增加命令和技能目录、搜索及调用入口。各引擎能力不同；Claude 的相关命令需切换到同一终端手动执行。
- 改进长对话展示、工作过程折叠、文件变更查看、启动反馈和输入响应。
- 首次使用 CLI 时提供安装引导和独立 Node 运行时，修复部分会话选择及启动问题。

## 工作区与插件

- 增加离线只读 PDF 预览，统一辅助面板的收起控制，并改进设置入口和插件图标。
- Blueprint、CPA 和 Docker 仍为可选官方插件，具体版本和安装包见下方附件。

## 已知限制

- 命令和技能的支持范围因 CLI 而异；Claude 对话模式中的相关命令需要在终端手动执行。远端原生输入历史尚未接入。
- Android 附件为局域网测试包，使用 debug 签名，需要与电脑处于同一局域网并重新扫码授权；长期稳定性和所有机型尚未验收。
- Docker 插件仍为实验功能。真实供应商、远端环境与长期使用场景的验证范围有限。
