# Provider icons

The model catalog resolves local artwork by the OpenRouter author slug. Use the slug as the filename for new images. A leading `~` uses the same artwork as the base author. Shared brands with a different slug have an alias in `catalog.ts`.

### Sources

Most SVGs come from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons). Catalog additions use `@lobehub/icons-static-svg` 1.106.0. The Aion Labs and Dolphin marks were rasterized at 64 px. The upstream MIT license is included in [LICENSE](./LICENSE). The OpenAI mark reuses the application's existing asset.

The following PNGs use the model authors' public Hugging Face avatars, sized to 64 px. The Recursive mark uses a dark background for contrast.
