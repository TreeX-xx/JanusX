# Plugin icons

- `cpa.jpg`: CPA management UI logo, from https://github.com/router-for-me/Cli-Proxy-API-Management-Center/blob/main/logo.jpg (retrieved 2026-11-03).
- `docker.svg`: Docker documentation whale vector icon (filled Docker blue), from https://github.com/docker/docs/blob/main/assets/icons/Whale.svg (retrieved 2026-11-03). Docker brand artwork remains owned by Docker.
- `blueprint.svg`: original JanusX artwork: an engineering sheet with a folded corner, drafting grid and connected module nodes. Designed for the 40px discovery card avatar.

These assets are bundled with the renderer and mapped by exact official plugin ID. Discovery does not need a network request or an installed plugin to display them. Unknown IDs and failed image loads retain the initial-letter fallback. This is a host-owned artwork mapping, not a new manifest or signed catalog field; new official icons require a host update.
